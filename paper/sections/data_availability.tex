\section*{Data and code availability}
The source code, configuration files, data-generation and evaluation scripts,
and plotting scripts are available at
\url{https://github.com/1zuki/tsunami-surrogate}. The repository contains the
resolved experiment configurations, evaluation programs, and plotting code
needed to reconstruct the reported analyses from the corresponding datasets and
checkpoints.

Before publication, the common-time processed datasets, frozen contract,
requested-time vector, normalization statistics, evaluation summaries,
selected checkpoints, and checksums will be deposited in an immutable public
archive, and this statement will be updated with its persistent identifier.
The eta-primary raw publications occupy approximately 31\,GB locally and can
be regenerated from the released scripts and frozen configurations.

The real-bathymetry diagnostic crops were derived from the GEBCO\_2026 Grid \citep{gebco2026}; we acknowledge the GEBCO Bathymetric Compilation Group 2026 and the NERC EDS British Oceanographic Data Centre NOC for providing the dataset.

Until that deposit is published, the repository should be treated as the
implementation source rather than as a complete immutable reproduction package
for the reported results.
