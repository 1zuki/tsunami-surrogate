\section*{Data and code availability}
The source code, configuration files, data-generation and valuation scripts, and plotting scripts are available at \url{https://github.com/1zuki/tsunami-surrogate}. The repository contains the resolved experiment configurations, evaluation programs, and plotting code needed to reconstruct the reported analyses from the corresponding datasets and checkpoints.

The versioned reproduction package containing the common-time processed datasets, frozen contract, requested-time vector, normalization statistics, selected checkpoints, validated evaluation artifacts, manuscript snapshot, and checksums is archived on Zenodo at \url{https://doi.org/10.5281/zenodo.21956834}. The complete eta-primary raw numerical publications, approximately 31\,GB, are distributed through a supplementary public mirror at \url{https://drive.google.com/drive/folders/1avJBArJGgdoosuNRyZMHKqgd3kWX3U84?usp=sharing}. Because the Google Drive folder is mutable, it should be treated as a distribution mirror rather than as the persistent archival identifier. The raw publications can also be regenerated from the released scripts and frozen configurations.

The real-bathymetry diagnostic crops were derived from the GEBCO\_2026 Grid \citep{gebco2026}; we acknowledge the GEBCO Bathymetric Compilation Group 2026 and the NERC EDS British Oceanographic Data Centre NOC for providing the dataset.
