\section*{Data and code availability}
The source code, configuration files, data-generation and evaluation scripts, plotting scripts, and the result files (JSON/CSV) underlying every table and figure in this paper are publicly available at \url{https://github.com/1zuki/tsunami-surrogate}.

The processed benchmark datasets (model-ready train/validation/test arrays for the hydrostatic, MUSCL-HR, and Boussinesq references), together with the scenario manifests, train/validation/test scenario identifiers, normalization statistics, and checksums, are archived with a persistent identifier at [Zenodo/OSF DOI]. The full raw rollout archive ($\approx$[XXX]\,GB) can be regenerated from the released scripts and configuration files; a mirror is additionally available at [external storage URL].

Trained model checkpoints are not redistributed in full, but the released
repository includes the resolved configurations, random seeds, the checkpoint-selection rule, the final per-model metrics, and the training histories needed to reproduce the reported results.
