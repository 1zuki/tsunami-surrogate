\section*{Data and code availability}
The source code, configuration files, data-generation and evaluation scripts, and plotting scripts are available at \url{https://github.com/1zuki/tsunami-surrogate}. The repository contains the resolved experiment configurations, evaluation programs, and plotting code needed to reconstruct the reported analyses.

The processed-data record provides model-ready common-time trajectories for 13,500 shared synthetic scenarios (10,000 for training, 1,000 for validation, and 2,500 for testing) from the Hydrostatic, MUSCL-HR, and study-defined Boussinesq-type references. It also includes pooled-reference data, preprocessing settings, and processed data on $32 \times 32$, $64 \times 64$, and $128 \times 128$ grids (Zenodo DOI: \url{https://doi.org/10.5281/zenodo.22997509}). The companion raw-data record contains solver outputs for the same three splits and raw outputs on these three grids (Zenodo DOI: \url{https://doi.org/10.5281/zenodo.22997523}). Both records provide manifests and SHA-256 checksums for the download parts and reconstructed archives.

The Zenodo records do not include the model checkpoints used for the reported evaluations. Selected checkpoints are available from the corresponding author upon reasonable request.

The real-bathymetry diagnostic crops were derived from the GEBCO\_2026 Grid \citep{gebco2026}; we acknowledge the GEBCO Bathymetric Compilation Group 2026 and the NERC EDS British Oceanographic Data Centre NOC for providing the dataset.
